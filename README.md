# 飞机大战

一个基于 Pygame 的纵版飞机射击小游戏（Python 3），支持鼠标 / 键盘操控、道具补给、多等级难度与最高分记录。

## 功能特性

- 小、中、大三种敌机，击落有不同得分
- 补给道具：双倍子弹、超级炸弹
- 5 个难度等级，随得分逐步升级、敌机提速
- 3 条生命，碰撞后短暂无敌
- 暂停 / 继续功能，最高分本地记录（`record.txt`）
- 完整的音效与背景音乐

## 环境要求

- Python 3.6+
- Pygame 2.0+

## 安装与运行

```bash
# 安装依赖
pip install -r requirements.txt

# 运行游戏
python main.py
```

## 操作说明

| 操作 | 按键 / 方式 |
| --- | --- |
| 移动飞机 | 鼠标移动，或 `W` / `A` / `S` / `D`、方向键 |
| 释放炸弹 | `Space`（需先拾取炸弹补给） |
| 暂停 / 继续 | 点击右上角暂停按钮 |

## 项目结构

```
.
├── main.py        # 游戏主程序
├── myplane.py     # 我方飞机
├── enemy.py       # 敌方飞机（小 / 中 / 大）
├── bullet.py      # 子弹
├── supply.py      # 补给道具
├── images/        # 游戏图片资源
├── sound/         # 音效与背景音乐
├── font/          # 字体文件
└── record.txt     # 最高分记录（自动生成）
```
